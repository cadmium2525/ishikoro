# いしころ（仮題）

今日の石を、家まで連れて帰ろう。

学校から家まで、道端の石を蹴って運ぶノスタルジック物理アクション。Three.js 製、GitHub Pages で動く静的 Web ゲーム。

## 現在の状態：Phase 3（くり返し遊べる）

毎回ちがう主人公・石・通学路・空模様で下校する。

### 通学路の自動生成

学校を出て、車が行き交う道（道A）の西側の歩道を北へ進み、西の路地へ曲がって家に着く。
歩道ぞいは次の区間を組み合わせ、路地は 1 本か、途中で北へ折れる 3 本でできる。

| 区間 | 内容 |
| --- | --- |
| 住宅街 | ブロック塀。車庫の切り下げや電柱がある |
| 商店街 | 店先に自転車や立て看板（歩道の外側の端だけ） |
| 田んぼ | 塀がなく、歩道から落ちると石は田んぼへ |
| 公園 | 低い柵と入口。入口から植え込みに入ると見つからない |
| 空き地 | 草むらに入ると見つからない |
| 横道の入口 | 車の来ない横道。両側に側溝 |
| 交差点 | 大通りと信号つき横断歩道（1日に最大 2 か所） |
| 路地 | 片側に側溝（ふたの割合は難しさで変わる）。田んぼぞいの区間もある |

- 難しさ（やさしい・ふつう・むずかしい）は日ごとに決まり、道の長さ・車の多さ・集水ますの間隔・
  側溝のふた・路地の幅・区間の出やすさが変わる。家に近いほど田んぼや空き地が出やすい
- 必ず攻略できるように、通れる幅（歩道 2.5 m、路地 3.4 m 以上）を残し、側溝は路地の片側だけ、
  障害物は歩道の外側の端だけに置く。家の門の前の側溝にはふたがある
- 2000 通りの種で、帰り道の中心線が危険な場所・塀・電柱・障害物に重ならず家に着くことを確認している

### 歩道と車道

- 歩道は車道より一段高い。車道側から転がってきた石は縁石で跳ね返り、歩道から車道へは段差を落ちる
- 車道から歩道へ戻すには、**切り下げ**（車庫の出入口、横道や路地の入口、横断歩道の端）を通すか、強く蹴って縁石を跳び越える
- 車は左側通行。歩道側の車線は向こうから車が来るので早めに見える
- 子どもは歩道を歩き、車道の石は一番近い歩道の位置まで行ってから、近くの車線に車が来ていないとき
  （大通りはその交差点の歩行者信号が青のとき）だけ降りて取りに行く。車は子どもに気づいて止まるが、石には気づかない
- 車が石に近づいていると、路面に黄色い矢印が出る。走行音は近くを車が通るほど大きくなる

### 失敗（その日の下校が終わる）

車道の路肩の**集水ます**、ふたのない**側溝**、**田んぼ**、**草むら**（空き地・公園の植え込み）に石が入る。
または走っている**車**に石が当たる（止まっている車には跳ね返るだけ）。

### 主人公・石・空

- 主人公：肌・髪型（短髪・おかっぱ・ポニーテール・ふたつ結び）・通学帽（黄色い帽子・紅白帽）・
  服・半ズボン／長ズボン／スカート・ランドセルの色（黄色いカバー）・背の高さ。家の外観も変わる
- 石：大きさ・質量・丸さ・食いつき・反発・偏心を毎回ランダムに決め、性格から呼び名がつく（例：「ちいさな おもたい まるいし」）
- 空：ひるさがり・ゆうがた・くもり

### 操作

1. 足元の方向ガイドが左右に往復 → **タップ**で方向決定
2. そのまま**長押し**で強さをチャージ（上端の斜線ゾーンは蹴りすぎ：狙いがぶれ、飛びすぎる。上限を超えると 0 に戻る）
3. 押したまま**左右にずらす**と回転（右にずらすと右へ曲がる）
4. **離して**キック

### 記録

持ち帰った石の数・成功率・最長の下校距離・これまで蹴った回数を localStorage に保存。
持ち帰った石は「いしの コレクション」に、呼び名・日付・蹴った回数・道のりと一緒に残る（最大 80 個）。

## 開発

```sh
npm install
npm run dev      # http://localhost:5173 （--host 付きなのでスマホから LAN 経由で確認可）
npm run build    # 型チェック + dist/ へビルド
```

### 調整しやすい値

| 場所 | 内容 |
| --- | --- |
| `src/input.ts` | 方向ガイドの振れ幅・往復速度、チャージ時間、回転のドラッグ量 |
| `src/stone.ts` | キック初速、転がり抵抗、カーブの強さ、石の個性の範囲 |
| `src/main.ts` | カメラ距離・角度、主人公の走る速さ、蹴りすぎ時のぶれ |
| `src/level.ts` | 通学路の生成（区間の種類と長さ・出やすさ、難しさごとの車の多さや集水ます・側溝のふた） |
| `src/traffic.ts` | 信号の周期、車の速度・ブレーキ |
| `src/kid.ts` | 主人公の見た目のバリエーション |

ブラウザのコンソールで `ishikoro.stone.traits` を見ると今回の石の性格が確認できる。`ishikoro.day(種)` で特定の通学路を作り、`ishikoro.stone.place(x, z)` と `ishikoro.chase()` で任意の地点から試せる。

# いしころ（仮題）

今日の石を、家まで連れて帰ろう。

学校から家まで、道端の石を蹴って運ぶノスタルジック物理アクション。Three.js 製、GitHub Pages で動く静的 Web ゲーム。

## 現在の状態：Phase 2（固定通学路を最後まで遊べる）

### 通学路（約140 m）

学校 → **車が行き交う道の歩道**（横道の入口・空き地の前を通る）→ **大通りとの交差点**（信号つき横断歩道）
→ 歩道の続き → 左の**路地**へ → 家の前のマットでクリア

- 歩道は車道より一段高い。車道側から転がってきた石は縁石で跳ね返り、歩道から車道へは段差を落ちる
- 車道から歩道へ戻すには、**切り下げ**（車庫の出入口、横断歩道の端）を通すか、強く蹴って縁石を跳び越える
- 車は左側通行。歩道側の車線は向こうから車が来るので早めに見える
- 横道と路地は車の来ない生活道路

### 失敗（その日の下校が終わる）

- 車道の路肩にある**集水ます**（格子のふた）に石がはまる
- ふたのない**側溝**（横道・路地）に石の中心が入る（ふたの上は安全）
- **草むら**（空き地）に入る
- 走っている**車**に石が当たる（止まっている車には跳ね返るだけ）

車道に石が出ただけでは失敗にならない。子どもは歩道を歩き、車道の石は一番近い歩道の位置まで行ってから、
近くの車線に車が来ていないとき（大通りは歩行者信号が青のとき）だけ降りて取りに行く。
車は子どもに気づいて止まるが、石には気づかないので、待っている間に車線上の石がはじかれることがある。

車が石に近づいていると、路面に黄色い矢印が出る。走行音は近くを車が通るほど大きくなる。

### 操作

1. 足元の方向ガイドが左右に往復 → **タップ**で方向決定
2. そのまま**長押し**で強さをチャージ（上端の斜線ゾーンは蹴りすぎ：狙いがぶれ、飛びすぎる。上限を超えると 0 に戻る）
3. 押したまま**左右にずらす**と回転（右にずらすと右へ曲がる）
4. **離して**キック

### そのほか

- 石の個性（大きさ・質量・丸さ・食いつき・反発・偏心）を毎回ランダム生成
- タイトル画面、クリア／ゲームオーバー画面、記録（持ち帰った数・成功率・最少キック数・最長距離）を localStorage に保存

通学路の自動生成・石コレクションなどは Phase 3 以降。

## 開発

```sh
npm install
npm run dev      # http://localhost:5173 （--host 付きなのでスマホから LAN 経由で確認可）
npm run build    # 型チェック + dist/ へビルド
```

### 調整しやすい値

| 場所 | 内容 |
| --- | --- |
| `src/input.ts` | 方向ガイドの振れ幅・往復速度、チャージ時間、回転のドラッグ量 |
| `src/stone.ts` | キック初速、転がり抵抗、カーブの強さ、石の個性の範囲 |
| `src/main.ts` | カメラ距離・角度、主人公の走る速さ、蹴りすぎ時のぶれ |
| `src/level.ts` | 通学路のレイアウト（車道・歩道・縁石と切り下げ・塀・集水ます・側溝・草むら・電柱・車線・家） |
| `src/traffic.ts` | 信号の周期、車の速度・出現間隔・ブレーキ |

ブラウザのコンソールで `ishikoro.stone.traits` を見ると今回の石の性格が確認できる。`ishikoro.stone.place(x, z)` と `ishikoro.chase()` で任意の地点から試せる。
